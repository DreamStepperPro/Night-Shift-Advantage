Cliftworks ("we", "our", or "us") provides the Night Shift Advantage mobile application. This Privacy Policy details how operational data, device identifiers, and operator information are handled, stored, automatically deleted, and manually removed upon request.

---

## 1. Core Architecture: Local-First Operation
Night Shift Advantage is built local-first. By default, all portioning math, machine settings, target weights, nugget setpoints, and historical scale checks are processed and stored client-side in an embedded SQLite database. The application functions completely offline without requiring active internet connectivity.

---

## 2. Information We Process
We collect and process minimal operational information necessary to execute precision waterjet portioning and shift tracking:
* **Operational Production Records:** Machine asset IDs (e.g., 4635, 4636), product modes (Lunch, Breakfast, Nuggets), target portion weights, waterjet cut densities, scale check averages, and equipment downtime logs.
* **Operator Identification (Personal Info):** Operator display names and optional local PINs entered during setup. These are used solely for shift ledger attribution, internal verification, and role-based access control (Operator, Supervisor, Admin). Providing a name is optional.
* **Device & User Identifiers:** When Cloud Synchronization is enabled, anonymous authentication identifiers (UIDs) generated by Google Firebase are used to maintain secure database sessions.

---

## 3. Data Transfers and Google Firebase
* **Zero Commercial Monetization:** We never sell, rent, monetize, or disclose operational records or operator identities to third-party advertisers or data brokers.
* **Cloud Synchronization:** When Cloud Synchronization is enabled by the user, data transmits to Google Firebase Realtime Database infrastructure to keep floor displays and equipment synchronized.
* **User-Controlled Gate:** Operators retain total authority to grant or revoke cloud sync at any time via the Cloud Sync toggle in application settings. Disabling this toggle immediately halts all outbound cloud data transmission and returns the app to isolated local mode.

---

## 4. Data Retention and Automatic Deletion Timelines
Data stored by Night Shift Advantage is subject to the following automated deletion schedules:
* **Local Scale Check Records (Device):** Historical weight checks, calculated densities, and scale records stored locally in SQLite are automatically purged after **7 days** via a rolling purge query executed on application launch.
* **Cloud Operational Logs:** Production records synchronized to Firebase Realtime Database are retained only for active production tracking and may be periodically purged or archived during scheduled database maintenance.

---

## 5. User Data & Account Deletion Requests
Users have the right to request the deletion of their operator profile, display name, and associated session records stored in our cloud database.

To request the deletion of your user data:
1. Send an email to **cliftonharalson@gmail.com**.
2. Set the subject line to: **DELETE REQUEST**.
3. Include your Firebase session **UID** (found in the app's Settings menu under Operator Profile & Admin).
4. Providing your operator display name is optional.

Upon receiving a valid request, we will manually delete the matching `/users/{uid}` node and associated cloud profile records from the Firebase database within 30 days.

Night Shift Advantage uses Google Firebase strictly as backend infrastructure when cloud features are active. Cliftworks assumes no liability for external server outages, network dropouts, or external infrastructure disruptions. The local mathematical portioning engine remains operational offline regardless of external connectivity.
